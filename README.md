# Devsy AUR Packages

AUR packages for [Devsy](https://devsy.sh/).

## Packages

- **devsy-bin** — Devsy CLI
- **devsy-desktop-bin** — Devsy Desktop (AppImage)

## Installation

```sh
yay -S devsy-bin
yay -S devsy-desktop-bin
```

## Updating

```sh
# find and update to latest
./update.sh

# update to a specific version
./update.sh 1.14.2
```
